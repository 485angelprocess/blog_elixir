# AnnabelleBlog

Elixir/phoenix/tailwind setup of a personal dev blog

```sh
mix deps.get
mix compile
mix site.build
```

`Tailwind` is installed through the nix flake. [Support post](https://discourse.nixos.org/t/cannot-run-tailwind-css-with-elixir-phoenix-1-8-project/69651/4).
The path is set so mix finds it
